# Calendar Heatmap

Calendar Heatmap adds a calendar view to Obsidian for navigating daily notes and visualizing writing activity with a heatmap.

## Features

- Open or create daily notes from a calendar view.
- Display heatmap intensity by created note count or words added.
- Optionally show and open weekly notes.
- Use Daily Notes or Periodic Notes settings where available.
- Customize week start, note folder, locale, and calendar font size.

## Usage

After installation, Calendar Heatmap opens in the right sidebar. 

Click a day to open or create its daily note. Enable weekly note display in the plugin settings to show week numbers and open weekly notes.

## Privacy

Calendar Heatmap runs locally inside Obsidian. It does not use network requests, telemetry, ads, or automatic update mechanisms.
